───────────────────────────────────────────────────────────────────
📊 ALGORITHME DE DÉTECTION
───────────────────────────────────────────────────────────────────

Score d'Opportunité (0-100 points) :
  • Impressions élevées : max 40 pts
  • Position 5-15 (page 2) : +20 pts
  • CTR faible malgré impressions : +20 pts
  • Quelques clics existants : +20 pts

Types d'Opportunités Détectés :
  1. high_impression_low_ctr → Améliorer titre/meta
  2. position_5_15 → Pousser en page 1
  3. zero_clicks → Revoir l'angle
  4. general → Potentiel à analyser

───────────────────────────────────────────────────────────────────
🚀 COMMENT UTILISER
───────────────────────────────────────────────────────────────────

ÉTAPE 1 : Configurer Google Service Account
  1. Créer Service Account dans Google Cloud Console
  2. Activer API "Google Search Console"
  3. Télécharger clé JSON
  4. Ajouter le compte à GSC (lecture seule)
  5. Configurer secrets Supabase :

     supabase secrets set GOOGLE_SERVICE_ACCOUNT_EMAIL="..."
     supabase secrets set GOOGLE_SERVICE_ACCOUNT_KEY="..."
     supabase secrets set OPENAI_API_KEY="sk-..."  # Optionnel

ÉTAPE 2 : Première Synchronisation
  1. Aller sur /backoffice/gsc-optimization
  2. Cliquer "Synchroniser GSC"
  3. Vérifier les opportunités détectées

ÉTAPE 3 : Générer du Contenu
  1. Onglet "Opportunités SEO"
  2. Sélectionner une requête à fort score
  3. Cliquer "Générer Contenu"
  4. Réviser, approuver, publier

ÉTAPE 4 : Suivre les Performances
  1. Attendre 2-4 semaines
  2. Vérifier amélioration position
  3. Comparer métriques avant/après
