## 🎥 VIDÉO 2 : Lancer un test A/B (3 min)

### Métadonnées
- **Titre :** Test A/B Email : Doublez votre taux de clic en 3 minutes
- **Description :** Découvrez comment tester scientifiquement vos emails pour trouver la version qui convertit le mieux. Méthode simple et efficace.
- **Tags :** #ABTesting #EmailMarketing #Optimisation #TaxiAssur
- **Durée :** 3:00
- **Niveau :** Débutant-Intermédiaire

### Script Complet

#### INTRO (0:00 - 0:15)

**[Écran titre : "Tests A/B : La méthode scientifique"]**

**NARRATEUR :**
> "Vous envoyez des emails, mais vous ne savez pas quelle version fonctionne le mieux ? Le test A/B est LA solution. En 3 minutes, je vous montre comment doubler votre taux de clic."

---

#### PARTIE 1 : Concept (0:15 - 0:45)

**[Animation expliquant le concept]**

**NARRATEUR :**
> "Le principe est simple :"

**[Graphique avec 2 branches]**

- **Version A** : 50% des prospects reçoivent cette version
- **Version B** : 50% reçoivent celle-ci

**NARRATEUR :**
> "Le système mesure automatiquement laquelle performe le mieux. Taux d'ouverture, clics, réponses, conversions. Tout est tracké."

**[Animation : données qui remontent dans des graphiques]**

**NARRATEUR :**
> "Après 7 jours, vous savez avec certitude quelle version utiliser pour le reste de vos campagnes."

---

#### PARTIE 2 : Création du test (0:45 - 2:00)

**[Retour écran]**

**NARRATEUR :**
> "Allons-y ! Onglet 'A/B Tests', puis 'Nouveau Test'."

**[Clics dans l'interface]**

**NARRATEUR :**
> "Nom du test : 'Sujet Court vs Long'. Toujours nommer clairement ce que vous testez."

**[Remplissage formulaire]**

**NARRATEUR :**
> "Type de test : je choisis 'Sujet email'. On teste UNE seule variable à la fois. Sinon, vous ne saurez pas ce qui a marché."

**[Sélection radio button]**

**NARRATEUR :**
> "Version A : sujet court et direct."

**[Tape dans champ]**
```
{{firstName}}, -30% sur votre assurance taxi
```

**NARRATEUR :**
> "Version B : sujet plus informatif et localisé."

**[Tape dans champ]**
```
{{firstName}}, comment économiser 800€/an sur votre assurance taxi à {{city}}
```

**NARRATEUR :**
> "Template : je sélectionne 'Offre Spéciale' pour les deux. On teste UNIQUEMENT le sujet, pas le contenu."

---

#### PARTIE 3 : Configuration (2:00 - 2:40)

**[Scroll vers paramètres]**

**NARRATEUR :**
> "Métrique principale : je choisis 'Taux de clic'. Pourquoi ? Parce que les clics mènent aux conversions."

**[Sélection dropdown]**

**NARRATEUR :**
> "Durée : 7 jours minimum. Il faut du temps pour des résultats statistiquement fiables."

**[Ajustement slider]**

**NARRATEUR :**
> "Échantillon : 100 leads minimum. 50 pour A, 50 pour B."

**[Validation champs]**

**NARRATEUR :**
> "Le système calcule automatiquement la significativité statistique. Vous n'avez pas à vous soucier des maths !"

---

#### PARTIE 4 : Résultats (2:40 - 2:50)

**[Clic "Lancer le test"]**

**NARRATEUR :**
> "Test lancé ! Les emails partent automatiquement. Dans 7 jours, vous aurez vos résultats."

**[Animation fast-forward vers dashboard résultats]**

**NARRATEUR :**
> "Exemple de résultat : Version B gagne avec +50% de clics ! Le système vous recommande automatiquement d'utiliser cette version pour tous vos futurs envois."

---

#### CONCLUSION (2:50 - 3:00)

**NARRATEUR :**
> "Testez, testez, testez ! C'est comme ça qu'on passe de 'moyen' à 'excellent'. Prochaine vidéo : les notifications pour ne rien rater."
