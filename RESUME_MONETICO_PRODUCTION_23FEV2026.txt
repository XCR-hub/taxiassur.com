1️⃣  RÉCUPÉRER LA CLÉ MAC DE PRODUCTION
────────────────────────────────────────────────────────────

   ⚠️  La clé MAC de production est DIFFÉRENTE de celle de test

   Où la trouver ?
   → https://www.monetico-services.com/fr
   → Menu : Configuration > Paramètres TPE
   → Section : Clé de sécurité / Clé MAC
   → Format : 40 caractères hexadécimaux

   Exemple : 106FA85BF342FD4EE95C883D82865B5CC1F63890

────────────────────────────────────────────────────────────

   OPTION A - Script automatique (recommandé) :
   ──────────────────────────────────────────
   ./scripts/configure-monetico-production.sh


   OPTION B - Commandes manuelles :
   ──────────────────────────────────────────
   supabase secrets set MONETICO_MODE="production"
   supabase secrets set MONETICO_TPE="7374133"
   supabase secrets set MONETICO_SOCIETE="taxiassur"
   supabase secrets set MONETICO_MAC_KEY="VOTRE_CLE_MAC_PRODUCTION"


   OPTION C - Via Dashboard Supabase :
   ──────────────────────────────────────────
   https://supabase.com/dashboard/project/bpwcakjtwgdtfwghylwv
   → Settings > Edge Functions > Secrets

   À FAIRE :
   ✓ Ne JAMAIS committer la clé MAC dans le code
   ✓ Ne JAMAIS exposer la clé MAC dans les logs
   ✓ Vérifier la signature MAC de TOUS les webhooks
   ✓ Utiliser HTTPS uniquement

   ✗ Désactiver la vérification MAC du webhook
   ✗ Stocker les numéros de carte (PCI-DSS)
   ✗ Logger les données sensibles
