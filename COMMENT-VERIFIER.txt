  🚨 QUE FAIRE SI VOUS AVEZ DES ERREURS ?
═══════════════════════════════════════════════════════════════

❌ ERREUR: "Variable d'environnement manquante"
→ Ouvrez le fichier .env
→ Ajoutez la variable manquante
→ Relancez npm run verify

❌ ERREUR: "Table introuvable"
→ Allez dans Supabase Dashboard > SQL Editor
→ Exécutez les migrations dans /supabase/migrations/

❌ ERREUR: "Edge Function non déployée"
→ Déployez la fonction manquante
→ Voir guide: DEPLOY-EDGE-FUNCTION-GUIDE.md

❌ ERREUR: "CRON job non actif"
→ Allez dans Supabase Dashboard > Database > Cron Jobs
→ Créez et activez le CRON manquant

❌ ERREUR: "Secret manquant"
→ Allez dans Supabase Dashboard > Settings > Vault
→ Ajoutez le secret manquant (OPENAI_API_KEY, etc.)
