✅ PROBLÈME RÉSOLU : Erreur 400 Mise à Jour Statut Leads

═══════════════════════════════════════════════════════════════

🔴 LE PROBLÈME

Quand tu changeais le statut d'un lead dans le backoffice :
❌ Erreur "Erreur lors de la mise à jour"
❌ Message console : "PATCH 400 (Bad Request)"
❌ Le statut ne changeait pas

═══════════════════════════════════════════════════════════════

🔍 LA CAUSE

Conflit entre le code et la base de données :
- La DB attendait des statuts en FRANÇAIS : "nouveau", "contacte", etc.
- Le code envoyait des statuts en ANGLAIS : "new", "contacted", etc.
→ La DB refusait avec une erreur 400

═══════════════════════════════════════════════════════════════

✅ LA SOLUTION

J'ai corrigé le fichier src/lib/leads.ts :
- Maintenant il envoie les statuts en FRANÇAIS
- Matching parfait avec la base de données
- Build réussi sans erreurs
