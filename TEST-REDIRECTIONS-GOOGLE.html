⚠️ Note importante

Ce test utilise l'API fetch() qui peut être bloquée par CORS. Si le test ne fonctionne pas ici, utilise plutôt :

  • Option 1 : https://httpstatus.io/ (Recommandé)
  • Option 2 : DevTools du navigateur (F12 → Network)
  • Option 3 : Extension navigateur "Redirect Path"

📋 Que faire après ?

  1. ✅ Vérifie que toutes les URLs affichent 301
  2. 📤 Si ce n'est pas le cas, upload public/.htaccess sur IONOS
  3. 🔄 Va dans Google Search Console → Indexation → Pages
  4. ✅ Clique "Valider le correctif" sur les pages avec redirection
  5. ⏰ Attends 3-7 jours que Google re-crawle
