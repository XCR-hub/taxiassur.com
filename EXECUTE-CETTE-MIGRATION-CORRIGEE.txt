❓ QUESTIONS FRÉQUENTES

Q: "Duplicate key error" sur website
R: Normal ! Signifie que certains prospects existent déjà.
   La migration utilise ON CONFLICT DO NOTHING pour éviter les doublons.
   Continue, les autres données seront ajoutées.

Q: "Table backlink_campaigns does not exist"
R: Normal ! Cette table est optionnelle.
   La migration utilise IF EXISTS pour la vérifier.
   Les prospects et métriques seront quand même ajoutés.

Q: Les pages affichent toujours 0
R: 3 étapes:
   1. Rafraîchis avec Ctrl+F5 (cache navigateur)
   2. Vérifie le .env contient les bonnes clés Supabase
   3. Vérifie dans Supabase SQL Editor:
      SELECT COUNT(*) FROM partner_prospects;

Q: Comment vérifier que ça a fonctionné ?
R: Dans Supabase SQL Editor, exécute:

   -- Vérifier les prospects
   SELECT COUNT(*) as total_prospects FROM partner_prospects;

   -- Vérifier les métriques
   SELECT COUNT(*) as total_metrics FROM automation_metrics;

   -- Vérifier les cron jobs
