AVANT (PROBLÈME):
export const supabase = createClient(url, key);
→ Initialisation immédiate au chargement module
→ Dépendance circulaire avec autres modules
→ "Cannot access 'createClient' before initialization"

APRÈS (RÉSOLU):
Lazy Initialization + Proxy Pattern

let supabaseInstance = null;

const getSupabaseInstance = () => {
  if (!supabaseInstance) {
    supabaseInstance = createClient(url, key);
  }
  return supabaseInstance;
};

export const supabase = new Proxy({}, {
  get(target, prop) {
    const instance = getSupabaseInstance();
    return instance[prop];
  }
});

Avantages:
✅ Initialisation retardée (lazy)
✅ Pas d'appel createClient au niveau module
✅ Pas de dépendance circulaire
✅ Transparent pour le code existant (proxy)
✅ Performance identique après 1er appel
