POURQUOI VIDER LE CACHE ?

Le navigateur garde en mémoire :
- Les fichiers JavaScript compilés (.js)
- La structure de la base de données
- Les appels API

Même si vous avez modifié la base, le navigateur utilise
encore l'ancien code qui pense que "author" est UUID.

Vider le cache = forcer le navigateur à recharger TOUT.
