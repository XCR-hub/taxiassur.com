Dans Supabase SQL Editor, exécute :

SELECT jobname, schedule, active
FROM cron.job
WHERE jobname LIKE '%blog%';

📊 ANALYSE :
  ✅ schedule = '0 10 * * *'   → CORRECT (1x/jour)
  ❌ schedule = '* * * * *'    → BUG (toutes les minutes!)
  ❌ schedule = '*/1 * * * *'  → BUG (toutes les minutes!)

Si tu as des articles en double, exécute :

DELETE FROM blog_posts
WHERE id IN (
  SELECT id FROM (
    SELECT id, ROW_NUMBER() OVER (
      PARTITION BY slug ORDER BY created_at DESC
    ) as rn
    FROM blog_posts
    WHERE category = 'actualites'
  ) t WHERE rn > 1
);
