- **Compteurs en temps réel** sur chaque colonne

### 2. 📊 Dashboard Intelligent

#### Stats principales (rafraîchies toutes les 15 secondes)
- **Total Leads** : Nombre total de prospects
- **Nouveaux Aujourd'hui** : Leads arrivés aujourd'hui (CHAUDS !)
- **Clients** : Nombre de conversions réussies
- **Pipeline** : Valeur totale des opportunités en cours
- **Taux de Conversion** : Performance globale en %

### 3. 🧠 IA Autonome Ultra-Performante

#### Suggestions Intelligentes
L'IA analyse automatiquement chaque lead et génère :

**Types de suggestions :**
- 🔥 **CRITICAL** : Lead ultra-chaud, action immédiate requise
- ⚠️ **HIGH** : Opportunité importante ou relance urgente
- 💡 **MEDIUM** : Actions recommandées pour augmenter conversion

**Exemples de suggestions :**
- "🔥 LEAD ULTRA-CHAUD - Appeler MAINTENANT" (+60% conversion)
- "👀 Email ouvert - Intérêt confirmé" (+45% conversion)
- "💎 Opportunité en OR - 85% de chances" (+70% conversion)
- "⚠️ RELANCE URGENTE - 7 jours sans contact" (+35% conversion)
- "📄 Documents reçus - Lead qualifié" (+85% conversion)

#### Script de Vente Personnalisé
Pour **chaque lead**, l'IA génère un script complet avec :

1. **Accroche adaptée** (10-15 secondes)
   - Version "Lead chaud" si créé < 24h
   - Version "Lead engagé" si emails ouverts
   - Version "Standard" pour les autres

2. **Questions de qualification** (30 secondes)
   - Type de véhicule
   - Ancienneté chauffeur
   - Historique sinistres

3. **Proposition de valeur** (45 secondes)
   - Liste des garanties
   - Tarif personnalisé avec réduction
   - Comparaison avant/après

4. **Création d'urgence** (15-20 secondes)
   - Délai d'expiration de l'offre
   - Nombre de clients dans la ville
   - Pression sociale

5. **Closing efficace** (15 secondes)
   - Demande de documents
   - Engagement immédiat

6. **Bonus si hésitation**
   - 1er mois à -50%
   - Frais de dossier offerts
   - Garantie satisfait ou remboursé

7. **Réponses aux objections**
   - "C'est trop cher" → Arguments comparatifs
   - "Je dois réfléchir" → Questions de clarification
   - "Je veux comparer" → Urgence + flexibilité

#### Arguments de Vente Automatiques
L'IA suggère des arguments basés sur :
- Nombre de clients dans la ville du prospect
- Avis clients et témoignages
- Offres spéciales du moment
- Statistiques de conversion

### 4. 🎯 Analyse Comportementale Avancée

Pour chaque lead, le système calcule :

#### Température du Lead
- 🔥 **HOT** (Chaud) : Créé < 24h ET (email ouvert OU répondu OU >80% proba)
- 🌡️ **WARM** (Tiède) : Créé < 72h ET (email ouvert OU >60% proba)
- ❄️ **COLD** (Froid) : Tous les autres

#### Niveau d'Urgence
- 🚨 **CRITICAL** : Lead nouveau < 24h OU >7 jours sans contact
- ⚠️ **HIGH** : >3 jours sans contact ET >70% proba OU >5 jours sans contact
- 📌 **MEDIUM** : >2 jours sans contact
- ✅ **LOW** : Le reste

#### Score d'Engagement (0-100)
- Email ouvert : +30 points
- A répondu : +40 points
- Documents envoyés : +20 points
- Emails envoyés : +5 points
- Appels passés : +10 points

#### ☎️ Appel Téléphonique

- **Suggestions en temps réel**

## 🚀 Comment l'Utiliser

### Pour un Commercial Débutant

1. **Ouvrir le CRM** : https://taxiassur.com/backoffice/crm

2. **Regarder la colonne "Nouveau"** :
   - Les leads avec 🔥 sont ULTRA-CHAUDS → Appeler MAINTENANT
   - Les autres → Envoyer un email

3. **Cliquer sur un lead** pour voir :
   - Le panneau s'ouvre à droite
   - Lire les **Suggestions IA** en haut
   - Copier le **Script de Vente**
   - Noter les **Arguments de vente**

4. **Appeler le prospect** :
   - Cliquer sur "Appeler"
   - Lire le script mot à mot
   - Suivre les suggestions

5. **Après l'appel** :
   - **Déplacer la carte** vers "Contacté" (drag & drop)
   - Si intéressé → vers "Qualifié"
   - Si documents reçus → vers "Devis envoyé"
   - Si accord → vers "Client" 🎉

6. **Envoyer un email de suivi** :
   - Cliquer sur "Email"
   - Choisir un template
   - Personnaliser si besoin
   - Envoyer
