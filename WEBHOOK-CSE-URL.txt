📋 OÙ LA CONFIGURER ? (3 ÉTAPES)
═════════════════════════════════

ÉTAPE 1 : Google Search Console
→ https://search.google.com/search-console
→ Sélectionne ta propriété : taxiassur.fr

ÉTAPE 2 : Paramètres → Notifications
→ Menu gauche : Clique "Paramètres" (⚙️)
→ Onglet "Autres paramètres"
→ Section "Notifications"
→ Clique "Ajouter un webhook"

ÉTAPE 3 : Colle l'URL et Active
→ Champ URL : Colle l'URL ci-dessus
→ Sélectionne les événements :
  ✅ Erreurs d'indexation
  ✅ Changements de statut
  ✅ Problèmes de sécurité
→ Clique "Envoyer un test"
→ Si test réussi ✅ → Clique "Enregistrer"
