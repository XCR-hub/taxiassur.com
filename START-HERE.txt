LE PROBLÈME
-----------
Votre site affiche un écran noir car le fichier "env-config.js"
sur le serveur IONOS est au MAUVAIS FORMAT.

SERVEUR ACTUEL (MAUVAIS) :
  # Configuration TaxiAssur
  VITE_SUPABASE_URL=https://...

FORMAT REQUIS (BON) :
  // Configuration des variables d'environnement pour TaxiAssur
  window.ENV_CONFIG = {
    VITE_SUPABASE_URL: 'https://...',
  };


LA SOLUTION EN 3 ÉTAPES
-----------------------

1️⃣  IDENTIFIER LE BON FICHIER
   └─> Aller dans : VotreProjet/dist/
   └─> Clic droit sur : env-config.js
   └─> Ouvrir avec : Notepad
   └─> Vérifier : Première ligne = "//" (PAS "#")

2️⃣  UPLOADER SUR IONOS
   └─> https://www.ionos.fr → Login
   └─> Hosting → Gérer → Gestionnaire de fichiers
   └─> Supprimer l'ancien env-config.js
   └─> Upload le nouveau depuis dist/env-config.js

3️⃣  VÉRIFIER & TESTER
   └─> Ouvrir : https://taxiassur.com/env-config.js
   └─> Première ligne DOIT être : "// Configuration"
   └─> Vider cache : CTRL+SHIFT+DEL
   └─> Test : CTRL+SHIFT+N → taxiassur.com


COMMENT RECONNAÎTRE LE BON FICHIER ?
------------------------------------

✅ BON FICHIER :
   // Configuration des variables d'environnement pour TaxiAssur
