📝 Fonction: generate-inbox-response
───────────────────────────────────────────────────────────────────

Emplacement:
supabase/functions/generate-inbox-response/index.ts

Fonctionnalités:
✓ Lit les emails depuis email_inbox
✓ Détecte automatiquement le contexte (lead associé)
✓ Génère des réponses adaptées selon l'intent:
  • quote_request → Réponse commerciale avec devis
  • information → Réponse informative claire
  • interested → Réponse enthousiaste avec next steps
  • complaint → Réponse empathique avec résolution
  • general → Réponse professionnelle standard

✓ Adapte le ton selon le sentiment:
  • positive → Ton enthousiaste et chaleureux
  • negative → Ton empathique et apaisant
  • neutral → Ton professionnel et avenant

✓ Utilise GPT-4o-mini pour rapidité et coût optimal
✓ Génère du HTML directement (pas de conversion)
✓ Limite à 200 mots pour réponses concises
✓ Enregistre la réponse dans email_inbox.ai_response

📋 DÉPLOIEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ Déployer la nouvelle Edge Function

   Depuis Supabase Dashboard:
   • Allez dans Edge Functions
   • Create new function
   • Nom: generate-inbox-response
   • Copiez le contenu de:
     supabase/functions/generate-inbox-response/index.ts

   OU via CLI (si disponible):
   npx supabase functions deploy generate-inbox-response

2️⃣ Vérifier les secrets

   Dans Supabase Dashboard → Edge Functions → Secrets:
   • OPENAI_API_KEY doit être défini
   • SUPABASE_URL (auto)
   • SUPABASE_SERVICE_ROLE_KEY (auto)

3️⃣ Déployer le front-end

   • Uploadez /dist sur IONOS
   • Videz cache: Ctrl+Shift+Delete
   • Rechargez: Ctrl+F5

4️⃣ Tester

   • Backoffice → CRM → Inbox Multicanal
   • Sélectionnez un email
   • Cliquez "Générer avec IA"
   • Patientez 2-3 secondes
   • La réponse s'affiche avec preview HTML
