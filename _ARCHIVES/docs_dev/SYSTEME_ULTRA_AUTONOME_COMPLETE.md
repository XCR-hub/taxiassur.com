## 🎯 **WORKFLOW COMPLET AUTOMATISÉ**

### **Scénario 1: Nouveau Lead Arrive**

```
1. Lead créé dans CRM
   ↓
2. Pattern Learning analyse le comportement
   ↓
3. Score automatique calculé
   ↓
4. Si score > seuil → Alerte commercial
   ↓
5. Email de bienvenue envoyé automatiquement
   ↓
6. Relances programmées selon pattern optimal
   ↓
7. Monitoring continu du taux de réponse
   ↓
8. Si pas de réponse → Optimisation message
   ↓
9. Si conversion → Pattern renforcé
```

### **Scénario 2: Problème Détecté**

```
1. Monitoring détecte anomalie (ex: conversion faible)
   ↓
2. Self-Healer analyse le problème
   ↓
3. Décision prise par l'IA:
   - Option A: Correction automatique possible → Appliquée
   - Option B: Nécessite intervention → Alerte envoyée
   ↓
4. Correction appliquée
   ↓
5. Monitoring vérifie que le problème est résolu
   ↓
6. Pattern enregistré pour éviter récidive
```

### **Scénario 3: Email Entrant**

```
1. Email reçu sur inbox@taxiassur.fr
   ↓
2. Webhook déclenché automatiquement
   ↓
3. IA analyse l'intent (devis, question, réclamation...)
   ↓
4. Lead créé/mis à jour dans CRM
   ↓
5. Réponse automatique envoyée
   ↓
6. Si prioritaire → Notification commercial
   ↓
7. Score lead augmenté
```

## 📞 **CONFIGURATION EMAIL WEBHOOK**

Pour recevoir les emails entrants automatiquement:

1. **Dans votre serveur email** (Gmail, Outlook, etc.), configurez une règle:
   - Transférer tous les emails vers: `webhook@votre-domaine.com`

2. **Configurez le webhook** dans votre DNS:
   - Ajouter un enregistrement MX pointant vers Supabase
   - OU utiliser un service comme SendGrid Inbound Parse

3. **URL du Webhook:**
   ```
   https://[SUPABASE_URL]/functions/v1/inbound-email-handler
   ```

4. **Format attendu:**
   ```json
   {
     "from": "client@example.com",
     "fromName": "Nom Client",
     "subject": "Demande de devis",
     "text": "Bonjour, je souhaite..."
   }
   ```
