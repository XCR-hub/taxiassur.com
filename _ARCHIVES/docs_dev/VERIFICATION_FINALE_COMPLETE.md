## 💡 UTILISATION IMMÉDIATE

### Envoyer un SMS depuis le CRM:
```typescript
// Dans votre interface CRM
const sendSMS = async (leadId: string, message: string) => {
  const { data: lead } = await supabase
    .from('leads')
    .select('phone')
    .eq('id', leadId)
    .single();

  const response = await supabase.functions.invoke('send-sms', {
    body: { to: lead.phone, body: message }
  });

  console.log('SMS envoyé:', response.data);
};
```

### Créer une campagne SMS:
```sql
INSERT INTO sms_campaigns (
  name,
  message_template,
  scheduled_for,
  target_audience
) VALUES (
  'Bienvenue Nouveaux Leads',
  'Bonjour {{prenom}}, merci pour votre demande. Un conseiller vous contactera sous 24h.',
  NOW() + INTERVAL '1 hour',
  '{"status": "nouveau"}'::jsonb
);
```

### Suivre les interactions:
```sql
-- Voir tous les SMS envoyés aujourd'hui
SELECT * FROM sms_logs
WHERE sent_at::date = CURRENT_DATE
ORDER BY sent_at DESC;

-- Voir les réponses reçues
SELECT * FROM sms_received
WHERE received_at::date = CURRENT_DATE
ORDER BY received_at DESC;

-- Stats campagne
SELECT
  campaign_id,
  COUNT(*) as total_sent,
  SUM(CASE WHEN status = 'delivered' THEN 1 ELSE 0 END) as delivered,
  SUM(CASE WHEN status = 'failed' THEN 1 ELSE 0 END) as failed
FROM sms_logs
GROUP BY campaign_id;
```
