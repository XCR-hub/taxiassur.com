ERREUR ACTUELLE :
  POST /rest/v1/blog_posts 400 (Bad Request)

CAUSE :
  La colonne "author" dans blog_posts est de type UUID
  L'application envoie author: 'TaxiAssur' (TEXT)
  → Conflit de type → Erreur 400
