📊 RAPPORTS DISPONIBLES:

┌─────────────────────────────────────────────────────────────┐
│ GÉNÉRAL (Vue d'Ensemble)                                    │
└─────────────────────────────────────────────────────────────┘

✓ Sites Scrapés
  → Nombre total de sites détectés automatiquement
  → Nouvelles opportunités trouvées
  → Score qualité moyen

✓ Emails - Première Mise en Relation
  → Nombre d'emails initiaux envoyés
  → Taux d'ouverture (%)
  → Taux de bounce (%)

✓ Emails Ouverts
  → Nombre d'emails ouverts
  → % par rapport aux envoyés
  → Temps moyen d'ouverture

✓ Relances
  → 1ère relance (après 7 jours sans réponse)
  → 2ème relance (après 14 jours)
  → 3ème relance (après 21 jours)
  → Nombre de "no response" définitifs

✓ Sites Acceptés
  → Nombre de réponses positives
  → Nombre de réponses négatives
  → Taux d'acceptation (%)

✓ Backlinks Acquis
  → Nombre de backlinks actifs
  → Nombre de backlinks vérifiés
  → Nombre de backlinks cassés/supprimés

   • Date de création
   • Date de premier contact
   • Date de réponse

   • 3ème relance envoyée le...
   • Réponse reçue le...

🔗 BACKLINKS:
   • Notre backlink envoyé: URL
   • Leur backlink reçu: URL
   • Date de vérification
   • Statut vérification (pending/verified/broken)
   • Dernière vérification le...

📊 MÉTRIQUES AVANCÉES:
   • Domain Authority (DA)
   • Relevance Score
   • Estimated Traffic
   • Spam Score
   • Quality Score (calculé automatiquement)
