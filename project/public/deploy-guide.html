🚀 Guide de Déploiement TaxiAssur.com

Système SEO et d'acquisition de leads ultra-performant

React + TypeScript PHP Webhook Make Compatible SEO Optimized

📋 Checklist Pré-Déploiement

  • Serveur PHP 7.4+ avec support Apache
  • Accès FTP/SFTP ou panneau de contrôle
  • Nom de domaine configuré
  • Certificat SSL activé (HTTPS)
  • Variables d'environnement préparées

🛠️ Étapes de Déploiement

Étape 1 : Build Local

Exécutez le script de déploiement :

npm run deploy

Ou manuellement :

npm run build
node scripts/deploy.js

Étape 2 : Upload Serveur

Uploadez tout le contenu du dossier /dist vers la racine de votre hébergement web :

/votre-site/
├── index.html
├── assets/
├── content/
├── feeds/
├── webhooks/
│ └── make.php
├── .htaccess
├── config.php
└── test-webhook.html

Étape 3 : Configuration PHP

Créez un fichier .htaccess pour les variables d'environnement :

SetEnv MAKE_SECRET "votre_token_securise_2024"
SetEnv ADMIN_EMAIL "commercial@xcr.fr"
SetEnv SITE_URL "https://www.taxiassur.com"

Étape 4 : Tests de Fonctionnement

Vérifiez que tout fonctionne :

  • Site principal : https://votre-domaine.com/
  • Test webhook : https://votre-domaine.com/test-webhook.html
  • Backoffice : https://votre-domaine.com/backoffice
  • Sitemap : https://votre-domaine.com/feeds/sitemap.xml

🔧 Configuration Avancée

Variables d'Environnement

# Dans .htaccess ou panneau de contrôle
SetEnv MAKE_SECRET "votre_token_securise_2024"
SetEnv ADMIN_EMAIL "commercial@xcr.fr"
SetEnv SITE_URL "https://www.taxiassur.com"
SetEnv ADMIN_PASSWORD "mot_de_passe_backoffice"

Configuration SMTP (IONOS)

Modifiez config.php avec vos paramètres SMTP :

define('SMTP_HOST', 'smtp.ionos.fr');
define('SMTP_PORT', 587);
define('SMTP_USER', 'noreply@taxiassur.com');
define('SMTP_PASS', 'votre_mot_de_passe');

🧪 Tests Post-Déploiement

Test Webhook

curl -H "X-MAKE-SECRET: votre_token" \
https://votre-domaine.com/webhooks/make.php?action=ping

Test Formulaire Lead

Remplissez le formulaire sur la page d'accueil et vérifiez :

  • Réception email admin
  • Email de confirmation client
  • Redirection vers /merci

Test Backoffice

Accédez à /backoffice avec le mot de passe configuré.

🔗 Intégration Make

Configuration Webhook Make

URL : https://votre-domaine.com/webhooks/make.php

Headers requis :

Content-Type: application/json
X-MAKE-SECRET: votre_token_securise_2024

Actions Disponibles

  • ?action=upsert - Ajouter/modifier contenu
  • ?action=lead - Traiter un lead
  • ?action=regenFeeds - Régénérer sitemap/RSS
  • ?action=ping - Test de connectivité

⚠️ Points d'Attention
