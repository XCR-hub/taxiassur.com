## 📝 COMMENT GÉNÉRER DU CONTENU AVEC L'IA

### Exemple 1 : Générer un article de blog

1. Aller sur `/backoffice/ai-generator`
2. Sélectionner **Type** : Blog
3. **Mot-clé principal** : `assurance taxi électrique`
4. **Mots-clés secondaires** : `Tesla, hybrid, écologique, prime CEE`
5. Cliquer **Générer**
6. Attendre 10-30 secondes
7. Prévisualiser le contenu généré
8. Cliquer **Sauvegarder** → Article créé !

### Exemple 2 : Générer une page ville

1. Type : **Ville**
2. **Mot-clé principal** : `assurance taxi`
3. **Ville** : `Lille`
4. **Mots-clés secondaires** : `Nord, 59, métropole`
5. Générer → Page "Assurance Taxi Lille" créée

### Exemple 3 : Générer une FAQ

1. Type : **Blog** (ou créer type FAQ custom)
2. **Mot-clé principal** : `questions assurance taxi`
3. **Mots-clés secondaires** : `prix, garanties, sinistre, résiliation`
4. Générer → FAQ complète avec Q&R
