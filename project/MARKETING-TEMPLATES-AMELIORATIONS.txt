🗄️ BASE DE DONN\u00c9ES SUPABASE

Table: marketing_template_usage
├─ id (uuid)
├─ template_type (text) - whatsapp, linkedin, email, presse
├─ template_id (text) - identifiant unique
├─ action (text) - copy | download
├─ ambassador_code (text)
└─ created_at (timestamptz)

RLS Policies:
✅ Allow anonymous insert (backoffice)
✅ Allow anonymous select (stats)

Index:
✅ idx_created_at (DESC) - performance
✅ idx_template_id - recherche rapide

Nettoyage Auto:
✅ Fonction cleanup_old_marketing_usage()
✅ Supprime entr\u00e9es >90 jours

🔧 FONCTIONNALIT\u00c9S TECHNIQUES

1. Tracking Automatique
   → trackUsage(type, id, action)
   → Insert dans Supabase
   → Actualisation stats temps r\u00e9el

2. G\u00e9n\u00e9rateur QR Code
   → API qrserver.com
   → URL: /devis?ref={CODE}
   → T\u00e9l\u00e9chargement PNG 500x500

3. R\u00e9ducteur URL
   → Affichage URL compl\u00e8te
   → Copie avec tracking
   → Code ambassadeur inclus

4. Statistiques
   → Count copies by action
   → Most used template
   → Last copy timestamp
   → Total downloads

5. Personnalisation
   → Replace {CODE}
   → Replace {Pr\u00e9nom}
   → Replace {{name}}
   → Temps r\u00e9el
