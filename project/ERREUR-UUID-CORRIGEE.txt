═══════════════════════════════════════════════════════════════

🔴 L'ERREUR

ERROR: column "id" is of type uuid but expression is of type text

Le script FIX-BLOG-POSTS-STRUCTURE.sql tentait d'insérer du texte
dans une colonne UUID.

═══════════════════════════════════════════════════════════════

✅ LA CORRECTION

1. Supprimé la colonne 'id' de l'INSERT
   → PostgreSQL génère automatiquement l'UUID

2. Changé ON CONFLICT(id) → ON CONFLICT(slug)
   → Le slug est unique, pas besoin de l'ID

3. Changé WHERE id LIKE → WHERE slug LIKE
   → On recherche par slug maintenant
