✅ ERREUR "duplicate key value violates unique constraint" RÉSOLUE

═══════════════════════════════════════════════════════════════

PROBLÈME :
ERROR: 23505: duplicate key value violates unique constraint "city_pages_city_key"
DETAIL: Key (city)=(Paris) already exists.

═══════════════════════════════════════════════════════════════

CAUSE :
Tu as déjà importé Paris (et peut-être d'autres villes) dans la table.
Le script essayait de les réinsérer sans gérer les doublons.

═══════════════════════════════════════════════════════════════

SOLUTION APPLIQUÉE :

1️⃣ CITY PAGES
   Changé : ON CONFLICT (slug) DO UPDATE SET...
   En      : ON CONFLICT (city) DO UPDATE SET...

   Maintenant le script :
   ✅ Insère si la ville n'existe pas
   ✅ Met à jour si la ville existe déjà
   ✅ Utilise la contrainte unique sur "city" (correct)

2️⃣ FAQ ENTRIES
   Ajouté  : Contrainte unique sur "question"
   Changé  : ON CONFLICT DO NOTHING
   En      : ON CONFLICT (question) DO UPDATE SET...

   Maintenant le script :
   ✅ Insère si la question n'existe pas
   ✅ Met à jour si la question existe déjà
   ✅ Permet de réexécuter sans erreur
