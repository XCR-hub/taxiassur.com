🗄️ BASE DE DONNÉES SUPABASE

Table: qr_code_usage
├─ id (uuid)
├─ ambassador_code (text)
├─ action (text) - generate | scan
├─ template (text) - basic, business-card, flyer, sticker, vehicle
└─ created_at (timestamptz)

RLS Policies:
✅ Allow anonymous insert (tracking public)
✅ Allow anonymous select (stats backoffice)

Index:
✅ idx_created_at (DESC) - chronologique
✅ idx_ambassador_code - filtrage
✅ idx_action - compteurs

Fonctions SQL:
✅ get_qr_stats_by_ambassador() - stats détaillées
✅ cleanup_old_qr_usage() - nettoyage >180 jours

🔧 FONCTIONNALITÉS TECHNIQUES

1. Génération QR Code
   → API qrserver.com
   → Paramètres: size, color, bgcolor
   → URL: /devis?ref={CODE}&utm_source=qrcode&utm_medium={TEMPLATE}

2. Tracking Automatique
   → Insert dans qr_code_usage à chaque génération
   → Track template utilisé
   → Stats temps réel

3. Personnalisation
   → State: qrSize (256-1024)
   → State: qrColor (hex)
   → State: bgColor (hex)
   → Régénération auto onChange

4. Templates
   → 5 types prédéfinis
   → Sélection visuelle
   → UTM tracking par template

5. Impression
   → generatePrintTemplate()
   → Nouvelle fenêtre HTML
   → Style TaxiAssur intégré
   → window.print() auto

6. Export Batch
   → Loop async sur ambassadors
   → Délai 500ms entre chaque
   → État generatingBatch

7. Statistiques
   → loadStats() from Supabase
   → Count by action
   → Most popular code
   → Last generation
