## 🔧 CONFIGURATION BACKEND REQUISE

### API Génération Image

Le générateur unifié nécessite une API de génération d'image configurée dans `/api/generate-content.php`.

**Option 1 : DALL-E (OpenAI) - Recommandé**

```php
// Dans generate-content.php
if ($mode === 'unified' && isset($data['imagePrompt'])) {
  $prompt = $data['imagePrompt'] ?:
    "Professional taxi in {$city}, modern vehicle, golden lighting, high quality photo";

  $imageResponse = callOpenAI([
    'model' => 'dall-e-3',
    'prompt' => $prompt,
    'size' => '1792x1024',
    'quality' => 'hd',
    'style' => 'natural'
  ]);

  $content['blogPost']['featuredImage'] = $imageResponse['data'][0]['url'];
  $content['blogPost']['imageAlt'] = $prompt;
}
```

**Option 2 : Pexels (Gratuit)**

```php
if ($mode === 'unified') {
  $query = urlencode("{$keyword} taxi {$city}");
  $pexelsKey = getenv('PEXELS_API_KEY');

  $ch = curl_init("https://api.pexels.com/v1/search?query={$query}&per_page=1&orientation=landscape");
  curl_setopt($ch, CURLOPT_HTTPHEADER, ["Authorization: {$pexelsKey}"]);
  curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
  $response = json_decode(curl_exec($ch), true);

  if (isset($response['photos'][0])) {
    $content['blogPost']['featuredImage'] = $response['photos'][0]['src']['large2x'];
    $content['blogPost']['imageAlt'] = "Taxi professionnel à {$city} - {$keyword}";
  }
}
```

**Option 3 : Unsplash (Gratuit)**

```php
if ($mode === 'unified') {
  $query = urlencode("taxi {$city}");
  $imageUrl = "https://source.unsplash.com/1792x1024/?{$query}";

  $content['blogPost']['featuredImage'] = $imageUrl;
  $content['blogPost']['imageAlt'] = "Taxi professionnel à {$city} - {$keyword}";
}
```

## 📚 FAQ TECHNIQUE

### Q: Peut-on générer sans ville ?

**R:** Non, la ville est obligatoire en mode unifié car elle est utilisée pour :
- Créer la page ville
- Localiser les FAQ
- Contextualiser l'image

### Q: Que se passe-t-il si la ville existe déjà ?

**R:** Le générateur tente d'insérer la ville. Si elle existe déjà :
- Warning ignoré
- Article et FAQ créés normalement
- Page ville non mise à jour

### Q: Peut-on modifier le contenu avant publication ?

**R:** Non directement dans l'interface. Deux options :
1. Copier le contenu, modifier dans éditeur, publier manuellement
2. Publier puis éditer dans Supabase directement

### Q: Combien coûte une génération ?

**R:** Estimation avec OpenAI GPT-4 :
- Article 2000 mots : ~0.10€
- Page ville 1500 mots : ~0.08€
- FAQ 10 questions : ~0.05€
- Image DALL-E 3 : ~0.04€
**Total : ~0.27€ par génération complète**

### Q: Peut-on générer en masse ?

**R:** Oui, mais attention :
- Limite API OpenAI : 3500 requests/min
- Recommandé : 1 génération toutes les 2 secondes
- Pour 100 contenus : ~3 minutes + délais API

## 📞 SUPPORT

### Problèmes courants

**Erreur: "Génération échouée"**
```
Causes possibles :
1. API OpenAI non configurée
2. Clé API invalide
3. Quota dépassé
4. Timeout serveur (> 60s)

Solutions :
1. Vérifier OPENAI_API_KEY dans .env
2. Tester la clé manuellement
3. Attendre reset quota (1 heure)
4. Augmenter timeout PHP (120s)
```

**Erreur: "Publication échouée"**
```
Causes possibles :
1. Connexion Supabase échouée
2. RLS policies bloquantes
3. Slug en double

Solutions :
1. Vérifier .env Supabase
2. Utiliser adminClient (bypass RLS)
3. Ajouter timestamp au slug
```

**Image ne s'affiche pas**
```
Causes possibles :
1. API image non configurée
2. URL invalide
3. CORS bloqué

Solutions :
1. Configurer Pexels/Unsplash/DALL-E
2. Vérifier URL retournée
3. Ajouter headers CORS
```
