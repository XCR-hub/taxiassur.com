🔑 COMMENT CONFIGURER L'API (5 MINUTES)
════════════════════════════════════════

ÉTAPE 1 : ACTIVER L'API
------------------------
→ https://console.cloud.google.com/apis/library
→ Cherche "Google Search Console API"
→ Clique "Activer"

ÉTAPE 2 : CRÉER UNE CLÉ API
----------------------------
→ https://console.cloud.google.com/apis/credentials
→ "Créer des identifiants" → "Clé API"
→ COPIE la clé (ex: AIzaSyB1234...)
→ "Restreindre la clé" → Coche "Google Search Console API"
→ "Enregistrer"

ÉTAPE 3 : AJOUTER DANS SUPABASE
--------------------------------
→ https://drohhxrkoequjphvabvq.supabase.co
→ "Project Settings" → "Edge Functions" → "Secrets"
→ Nouveau secret :
  Nom : GOOGLE_SEARCH_CONSOLE_API_KEY
  Valeur : Ta clé API
→ "Save"

ÉTAPE 4 : TESTER
----------------
→ Backoffice SEO : https://taxiassur.fr/backoffice/seo
→ Clique "🔄 Rafraîchir Données SEO"
→ Patiente 5 secondes
→ Les données apparaissent ! ✅
