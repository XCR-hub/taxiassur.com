══════════════════════════════════════════════════════════════════════

✅ 3 FONCTIONS RPC AJOUTÉES:

1️⃣  get_blog_posts()
    └─ Retourne TOUS les articles publiés
    └─ Utilisé par la page /blog
    └─ Ordre: plus récents en premier

2️⃣  get_blog_post_by_slug(p_slug text)
    └─ Retourne UN article par son slug
    └─ Utilisé par les pages /blog/[slug]
    └─ Exemple: get_blog_post_by_slug('assurance-taxi-2024')

3️⃣  get_faq_entries()
    └─ Retourne TOUTES les FAQ
    └─ Utilisé par la page /faq
    └─ Ordre: par order_index puis date

══════════════════════════════════════════════════════════════════════

🔐 SÉCURITÉ:

• SECURITY DEFINER → Contourne RLS (sûr car on filtre published=true)
• GRANT EXECUTE TO anon → Les visiteurs peuvent appeler ces fonctions
• GRANT EXECUTE TO authenticated → Les admins aussi

══════════════════════════════════════════════════════════════════════

📊 STRUCTURE DES RETOURS:

get_blog_posts() retourne:
├─ slug (text)
├─ title (text)
├─ excerpt (text)
├─ content (text)
├─ tags (text[])
├─ created_at (timestamptz)
├─ updated_at (timestamptz)
└─ faq (jsonb)

get_faq_entries() retourne:
├─ id (uuid)
├─ question (text)
├─ answer (text)
├─ category (text)
└─ created_at (timestamptz)
