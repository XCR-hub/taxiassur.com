       🎯 PAS DE WEBHOOK ? SOLUTION API GOOGLE SEARCH CONSOLE
═══════════════════════════════════════════════════════════════════════

❌ LE PROBLÈME
══════════════

Tu n'as pas "Paramètres → Autres paramètres → Notifications → Webhook"
dans Google Search Console.

POURQUOI ?
- Fonctionnalité récente, pas disponible pour tous
- Interface peut varier selon ta version
- Nécessite parfois Google Workspace

✅ PAS GRAVE ! Il y a une meilleure solution : L'API directe !

═══════════════════════════════════════════════════════════════════════

✅ LA SOLUTION : API GOOGLE SEARCH CONSOLE
═══════════════════════════════════════════

Au lieu d'attendre des webhooks, on va INTERROGER directement l'API
pour récupérer toutes les données en temps réel.

AVANTAGES :
✅ Fonctionne pour TOUS les comptes
✅ Plus fiable qu'un webhook
✅ Contrôle total sur les données
✅ Données réelles : pages indexées, performances, position moyenne

═══════════════════════════════════════════════════════════════════════

🔑 ÉTAPE 1 : CRÉER UNE CLÉ API (5 MINUTES)
═══════════════════════════════════════════

1.1 ACTIVER L'API
-----------------
→ Va sur : https://console.cloud.google.com/apis/library
→ Cherche : "Google Search Console API"
→ Clique : "Activer" (Enable)

1.2 CRÉER UNE CLÉ API
---------------------
→ Va sur : https://console.cloud.google.com/apis/credentials
→ Clique : "Créer des identifiants" → "Clé API"
→ COPIE la clé générée (ex: AIzaSyB1234...)
→ Clique : "Restreindre la clé" (recommandé)
→ Dans "Restrictions relatives aux API" :
  - Sélectionne "Restreindre la clé"
  - Coche "Google Search Console API"
→ Clique : "Enregistrer"

1.3 AJOUTER LA CLÉ DANS SUPABASE
---------------------------------
→ Va sur : https://drohhxrkoequjphvabvq.supabase.co
→ Menu : "Project Settings" → "Edge Functions" → "Secrets"
→ Ajoute un nouveau secret :
  Nom : GOOGLE_SEARCH_CONSOLE_API_KEY
  Valeur : Ta clé API (celle copiée en 1.2)
→ Clique : "Save"

═══════════════════════════════════════════════════════════════════════

🚀 ÉTAPE 2 : TESTER (30 SECONDES)
═════════════════════════════════

Dans ton Backoffice :
---------------------
→ Va sur : https://taxiassur.fr/backoffice/seo
→ Clique le bouton : "🔄 Rafraîchir Données SEO"
→ Patiente 3-5 secondes
→ Les données se mettent à jour automatiquement !

TU DEVRAIS VOIR :
✅ Nombre de pages indexées (données réelles)
✅ Pages en attente
✅ Position moyenne
✅ Badge "✅ Données réelles depuis Google Search Console"

🐛 DÉPANNAGE

-------------------------
