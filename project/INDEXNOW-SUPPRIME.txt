## 💡 POURQUOI ?

IndexNow était une API pour notifier instantanément les moteurs 
de recherche (Bing, Yandex, etc.) des nouvelles pages.

Supprimé car :
- Pas essentiel pour le SEO
- Moteurs crawlent automatiquement
- Causait des erreurs de configuration
- Simplifie le système

Le SEO continuera de fonctionner normalement via :
- Sitemap.xml (toujours présent)
- Robots.txt (toujours présent)
- Meta tags SEO (toujours présents)
- Google Search Console (manuel)
