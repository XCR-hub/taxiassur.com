## ⚠️ Avant Production

Pour Monético PRODUCTION, demander à Ingineco :
- `MONETICO_TPE`
- `MONETICO_MAC_KEY`

Puis :
```bash
supabase secrets set MONETICO_MODE="production"
supabase secrets set MONETICO_TPE="VOTRE_TPE"
supabase secrets set MONETICO_MAC_KEY="VOTRE_CLE"
```
