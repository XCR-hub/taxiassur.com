Le nouveau processus — a partir d'aujourd'hui
Le systeme fait le travail de fond, vous vous concentrez sur la relation et la cloture
1

Lead entre via le formulaire Instant

Le prospect remplit le formulaire sur taxiassur.com. Le lead apparait immediatement dans le CRM avec toutes ses infos. Un email de confirmation lui est envoye automatiquement.

2

Notification commerciale Instant

Vous recevez une alerte dans le CRM (cloche en haut a droite). Le lead est en statut "Nouveau lead" dans le pipeline. Objectif : appeler dans les 2h.

3

Qualification + devis J+0 / J+1

Appel de qualification, saisie du devis dans le CRM, envoi via l'espace prospect personnalise. Le client valide ou refuse en ligne — vous etes notifie en temps reel.

4

Collecte documents + signature J+1 / J+3

L'espace prospect permet au client de deposer ses documents directement (carte grise, permis, carte taxi, RI, RIB). Vous validez chaque document dans le CRM. La signature electronique se fait en ligne.

5

Paiement + activation contrat J+3 / J+7

L'acompte est paye en ligne via Monetico (CB securise). A reception du paiement et de tous les documents, le contrat est transmis a la compagnie. L'attestation est envoyee au client.
