🔍 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────

❌ "Pas d'email reçu"
→ Attendre 1-2 minutes (le cron s'exécute toutes les minutes)
→ Vérifier la table email_queue

❌ "Lead pas visible dans le CRM"
→ Vérifier la table crm_leads
→ Le lead est créé immédiatement, pas d'attente

❌ "Token invalide"
→ Le token est généré automatiquement (64 caractères)
→ Vérifier la colonne access_token dans crm_leads
