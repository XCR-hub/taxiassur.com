# Procédures TaxiAssur

Pour les devis Generali et le parcours prospect, lire `docs/guides/procedure-generali-taxiassur.txt`.
Ce document distingue les codes vérifiés, les préférences du cabinet et les difficultés du dossier pilote.
Reprendre le véhicule réellement demandé et les réponses confirmées, sans déduire les données du nouveau véhicule d'un ancien relevé d'assurance.
Ne pas transformer les contournements observés dans un dossier en réponses fictives automatiques pour les autres prospects.
Les secrets, PDF clients et preuves d'envoi restent dans les répertoires privés ignorés par Git.
