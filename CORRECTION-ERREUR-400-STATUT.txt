1. MAPPING TypeScript → DB
---------------------------
Quand tu changes le statut dans le backoffice :

TypeScript (Interface)  →  Conversion  →  Database (Supabase)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
nouveau                 →               →  new
contacte                →               →  contacted
devis_envoye            →               →  interested
client                  →               →  converted
perdu                   →               →  lost

2. MAPPING DB → TypeScript
---------------------------
Quand tu affiches les leads :

Database (Supabase)  →  Conversion  →  TypeScript (Interface)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
new                  →               →  nouveau        🔵 Nouveau
contacted            →               →  contacte       🟡 Contacté
interested           →               →  devis_envoye   🟣 Devis Envoyé
converted            →               →  client         🟢 Client
lost                 →               →  perdu          🔴 Perdu

3. RÉSULTAT
-----------
✅ Tu vois "Nouveau", "Contacté", etc. dans l'interface (français)
✅ La base de données stocke "new", "contacted", etc. (anglais)
✅ La conversion est automatique et transparente
