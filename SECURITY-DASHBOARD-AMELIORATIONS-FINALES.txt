🗄️ BASE DE DONNÉES SUPABASE

Table: security_logs
├─ id (uuid)
├─ timestamp (timestamptz)
├─ level (text) - ERROR, WARNING, INFO, SUCCESS
├─ message (text)
├─ ip (text)
├─ user_agent (text)
├─ path (text)
├─ method (text)
├─ status_code (integer)
├─ blocked (boolean)
├─ threat_type (text)
├─ context (jsonb)
└─ created_at (timestamptz)

RLS Policies:
✅ Allow anonymous select (backoffice)
✅ Allow anonymous insert (tracking auto)

Index:
✅ idx_created_at (DESC) - chronologique
✅ idx_ip - filtrage par IP
✅ idx_level - filtrage par niveau
✅ idx_blocked - menaces bloquées
✅ idx_threat_type - types de menaces

Fonctions SQL:
✅ get_security_stats(interval) - stats agrégées
✅ cleanup_old_security_logs() - nettoyage >90 jours

🔧 FONCTIONNALITÉS TECHNIQUES

1. Chargement Données Réelles
   → supabase.from('security_logs').select('*')
   → Filter by time_range (1h/24h/7d/30d)
   → Order by created_at DESC
   → Limit 50 logs

2. Calcul Statistiques
   → Total requests: logs.length
   → Blocked: logs.filter(blocked=true)
   → Unique IPs: new Set(logs.map(ip))
   → Top threats: count by threat_type
   → IP analysis: count by ip + blocked

3. Score Sécurité
   → blockRate = (blocked / total) * 100
   → validRate = (leads / total) * 100
   → score = 100 - blockRate + validRate * 0.5
   → Capped at 100

4. Activité Horaire
   → Group logs by hour (0-23)
   → Count requests per hour
   → Calculate height: (count / max) * 100%
   → Render bars avec gradient

5. Mode Live
   → State: liveMode (boolean)
   → setInterval 30000ms
   → Auto loadSecurityData() si live
   → Indicator: pulsing green dot

6. Export Rapport
   → JSON.stringify(stats + logs + score)
   → Blob + URL.createObjectURL
   → Download link auto-click
   → Filename: security-report-{DATE}.json

7. Filtre Temps
   → getTimeRangeQuery() → ISO date
   → Supabase .gte('created_at', timeAgo)
   → Recalcul complet stats
