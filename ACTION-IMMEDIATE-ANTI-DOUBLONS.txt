Table créée : pexels_images_used

Fonctions disponibles :
- check_pexels_image_not_used(pexels_id, query)
  → Retourne true si image jamais utilisée

- register_pexels_image_used(...)
  → Enregistre une image comme utilisée

Usage dans tes Edge Functions :
```typescript
// Vérifier avant utilisation
const { data } = await supabase
  .rpc('check_pexels_image_not_used', {
    p_pexels_id: '1234567',
    p_search_query: 'taxi'
  });

if (data) {
  // Image OK, l'utiliser
  // Puis l'enregistrer
  await supabase.rpc('register_pexels_image_used', {
    p_pexels_id: '1234567',
    p_pexels_url: 'https://...',
    p_search_query: 'taxi',
    p_used_in_type: 'blog',
    p_used_in_id: 42
  });
}
```
