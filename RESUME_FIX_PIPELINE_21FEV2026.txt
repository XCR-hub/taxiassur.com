│ ❌ PROBLÈME                                                               │
└─────────────────────────────────────────────────────────────────────────┘

  Erreur: "Minified React error #300"
  Contexte: Passage d'une étape à une autre dans le pipeline
  Cause: Nombre de hooks différent entre les étapes

┌─────────────────────────────────────────────────────────────────────────┐
│ 🔍 DIAGNOSTIC                                                             │
└─────────────────────────────────────────────────────────────────────────┘

  React Error #300 = "Rendered more hooks than during the previous render"

  Problème dans: src/components/crm/PipelineWorkflow7Etapes.tsx

  - Étape 2 (CollecteDocumentsStep): 11 hooks
  - Étape 3 (SaisieDevisStep): nombre différent
  - Étape 4 (ValidationDevisStep): encore différent

  → React détecte changement de hooks → ❌ erreur #300

┌─────────────────────────────────────────────────────────────────────────┐
│ ✅ SOLUTION APPLIQUÉE                                                     │
└─────────────────────────────────────────────────────────────────────────┘

  Ajout de key={currentStage} sur le conteneur du contenu

  Fichier: src/components/crm/PipelineWorkflow7Etapes.tsx
  Ligne: 243

  AVANT:
    <div className="bg-white rounded-lg...">

  APRÈS:
    <div key={currentStage} className="bg-white rounded-lg...">

┌─────────────────────────────────────────────────────────────────────────┐
│ 💡 POURQUOI ÇA MARCHE                                                    │

    1. Démonter l'étape précédente
    2. Réinitialiser tous les hooks
    3. Monter une nouvelle instance
